COMO USAR

1. Coloque estes 4 arquivos na mesma pasta:
   - index.html
   - style.css
   - supabase.js
   - app.js

2. Abra/publica somente o index.html.

3. NÃO abra style.css, supabase.js ou app.js no navegador.
   Eles não são páginas; são arquivos de apoio do index.

Se aparecer um X no topo:
- o style.css não carregou
- confira se o arquivo está na mesma pasta do index.html
- confira se o nome está exatamente: style.css
